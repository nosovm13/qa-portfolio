# Authorization Test Cases

Тестовая документация для проверки формы авторизации в web/mobile web приложении.

## Что проверялось

- вход по email;
- вход по номеру телефона;
- обработка неверного пароля;
- валидация пустого логина;
- валидация пустого пароля;
- проверка некорректного email;
- обработка пробелов в логине;
- переключение видимости пароля;
- сценарии двухфакторной аутентификации.

## Виды тестирования

- функциональное тестирование;
- негативное тестирование;
- позитивное тестирование;
- smoke testing;
- regression testing;
- UI testing.

## Файлы

- `authorization_test_cases.xlsx` — тест-кейсы в формате таблицы;
- `authorization_test_cases.pdf` — версия для быстрого просмотра.
