# Authorization Test Cases

Учебный проект по тестированию формы авторизации Yandex ID в mobile web приложении.

## Объект тестирования

Форма авторизации в mobile web приложении.

## Что проверялось

- вход по email;
- вход по номеру телефона;
- обработка неверного пароля;
- обработка несуществующего логина;
- валидация пустого поля логина;
- валидация пустого поля пароля;
- проверка некорректного email;
- обработка пробелов в логине;
- переключение видимости пароля;
- сценарии двухфакторной аутентификации.

## Виды тестирования

- функциональное тестирование;
- позитивное тестирование;
- негативное тестирование;
- UI testing;
- smoke testing;
- regression testing.

## Тестовая среда

- Платформа: Mobile Web
- ОС: Android
- Браузер: Google Chrome

## Использованные инструменты

- Google Sheets;
- Google Chrome;
- Chrome DevTools.

## Файлы

- `test_plan.md` — краткий тест-план;
- `checklist.md` — чек-лист проверок;
- `authorization_test_cases.xlsx` — тест-кейсы в формате таблицы;
- `authorization_test_cases.pdf` — версия тест-кейсов для быстрого просмотра;
- `test_report.md` — краткий отчёт по результатам тестирования.
