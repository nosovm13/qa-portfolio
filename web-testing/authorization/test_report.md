# Test Report: Authorization

## Объект тестирования

Форма авторизации yandex ID в mobile web приложении.

## Цель тестирования

Проверить основные сценарии входа пользователя, обработку ошибок, валидацию полей и сценарии двухфакторной аутентификации.

## Тестовая среда

- Платформа: Mobile Web
- ОС: Android
- Браузер: Google Chrome

## Проверенные сценарии

- вход по email с валидными данными;
- вход по телефону с валидными данными;
- вход с неверным паролем;
- вход с несуществующим логином;
- валидация пустого поля логина;
- валидация некорректного email;
- обработка пробелов в логине;
- валидация пустого поля пароля;
- переключение видимости пароля;
- сценарии 2FA.

## Результат

Подготовлены тест-кейсы для позитивных и негативных сценариев авторизации. Проверены основные пользовательские сценарии, валидация полей и сообщения об ошибках.

## Использованные инструменты

- Google Sheets;
- Google Chrome;
- Chrome DevTools.
