# Test Report: Authorization

## Объект тестирования

Форма авторизации в Yandex ID mobile web приложении.

## Цель тестирования

Проверить основные сценарии входа пользователя, обработку ошибок, валидацию полей, UI-состояния формы и сценарии двухфакторной аутентификации.

## Тестовая среда

- Платформа: Mobile Web
- ОС: Android
- Браузер: Google Chrome

## Проверенные сценарии

- вход по email с валидными данными;
- вход по телефону с валидными данными;
- вход с неверным паролем;
- вход с несуществующим логином;
- валидация пустого поля логина;
- валидация некорректного email;
- обработка пробелов в логине;
- валидация пустого поля пароля;
- переключение видимости пароля;
- сценарии двухфакторной аутентификации.

## Виды тестирования

- функциональное тестирование;
- позитивное тестирование;
- негативное тестирование;
- UI testing;
- smoke testing;
- regression testing.

## Результат

Подготовлены тест-кейсы для проверки позитивных и негативных сценариев авторизации. Проверены основные пользовательские сценарии, валидация полей, сообщения об ошибках и элементы интерфейса формы входа.

Критичных блокирующих дефектов в рамках подготовленных проверок не зафиксировано.

## Использованные инструменты

- Google Sheets;
- Google Chrome;
- Chrome DevTools.
