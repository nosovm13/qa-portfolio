# Checklist: Authorization

## Форма авторизации

- [x] Форма авторизации открывается без ошибок.
- [x] Поле логина отображается.
- [x] Поле пароля отображается.
- [x] Кнопка входа отображается.
- [x] Элементы формы корректно отображаются на mobile web.
- [x] Текстовые элементы не обрезаются.
- [x] Поля ввода доступны для взаимодействия.

## Вход по email

- [x] Пользователь может ввести валидный email.
- [x] Пользователь может войти с валидным email и валидным паролем.
- [x] При вводе некорректного email отображается сообщение об ошибке.
- [x] При вводе несуществующего email отображается сообщение об ошибке.
- [x] Пробелы в начале и конце email обрабатываются корректно.

## Вход по телефону

- [x] Пользователь может ввести номер телефона.
- [x] Пользователь может войти с валидным номером телефона и валидным паролем.
- [x] При вводе несуществующего номера телефона отображается сообщение об ошибке.
- [x] Номер телефона с некорректным форматом не принимается.
- [x] Пробелы в номере телефона обрабатываются корректно.

## Пароль

- [x] Пользователь может ввести пароль.
- [x] При вводе неверного пароля отображается сообщение об ошибке.
- [x] При пустом поле пароля отображается сообщение об ошибке.
- [x] Кнопка показа/скрытия пароля работает корректно.
- [x] После переключения видимости значение пароля не изменяется.

## Валидация полей

- [x] При пустом поле логина отображается сообщение об ошибке.
- [x] При пустом поле пароля отображается сообщение об ошибке.
- [x] Невалидный email не принимается.
- [x] Поля с пробелами обрабатываются корректно.
- [x] Сообщения об ошибках понятны пользователю.
- [x] Ошибки отображаются рядом с соответствующими полями.

## Двухфакторная аутентификация

- [x] После ввода валидных данных отображается экран ввода кода 2FA, если 2FA включена.
- [x] Пользователь может ввести код подтверждения.
- [x] При вводе валидного кода 2FA авторизация завершается успешно.
- [x] При вводе невалидного кода 2FA отображается сообщение об ошибке.
- [x] Пустое поле кода 2FA не принимается.
- [x] Повторная отправка кода работает корректно, если такая функция доступна.

## UI и поведение формы

- [x] Фокус устанавливается в активное поле ввода.
- [x] Клавиатура на mobile web не перекрывает основные элементы формы.
- [x] Кнопка входа имеет понятное состояние.
- [x] Ошибки не ломают отображение формы.
- [x] После ошибки пользователь может исправить данные и повторить вход.

## Итоговая проверка

- [x] Основные позитивные сценарии проверены.
- [x] Основные негативные сценарии проверены.
- [x] Проверена валидация обязательных полей.
- [x] Проверены сообщения об ошибках.
- [x] Проверено базовое отображение на mobile web.
