# Checklist: Authorization

## Форма авторизации

- [ ] Форма авторизации открывается без ошибок.
- [ ] Поле логина отображается.
- [ ] Поле пароля отображается.
- [ ] Кнопка входа отображается.
- [ ] Элементы формы корректно отображаются на mobile web.
- [ ] Текстовые элементы не обрезаются.
- [ ] Поля ввода доступны для взаимодействия.

## Вход по email

- [ ] Пользователь может ввести валидный email.
- [ ] Пользователь может войти с валидным email и валидным паролем.
- [ ] При вводе некорректного email отображается сообщение об ошибке.
- [ ] При вводе несуществующего email отображается сообщение об ошибке.
- [ ] Пробелы в начале и конце email обрабатываются корректно.

## Вход по телефону

- [ ] Пользователь может ввести номер телефона.
- [ ] Пользователь может войти с валидным номером телефона и валидным паролем.
- [ ] При вводе несуществующего номера телефона отображается сообщение об ошибке.
- [ ] Номер телефона с некорректным форматом не принимается.
- [ ] Пробелы в номере телефона обрабатываются корректно.

## Пароль

- [ ] Пользователь может ввести пароль.
- [ ] При вводе неверного пароля отображается сообщение об ошибке.
- [ ] При пустом поле пароля отображается сообщение об ошибке.
- [ ] Кнопка показа/скрытия пароля работает корректно.
- [ ] После переключения видимости значение пароля не изменяется.

## Валидация полей

- [ ] При пустом поле логина отображается сообщение об ошибке.
- [ ] При пустом поле пароля отображается сообщение об ошибке.
- [ ] Невалидный email не принимается.
- [ ] Поля с пробелами обрабатываются корректно.
- [ ] Сообщения об ошибках понятны пользователю.
- [ ] Ошибки отображаются рядом с соответствующими полями.

## Двухфакторная аутентификация

- [ ] После ввода валидных данных отображается экран ввода кода 2FA, если 2FA включена.
- [ ] Пользователь может ввести код подтверждения.
- [ ] При вводе валидного кода 2FA авторизация завершается успешно.
- [ ] При вводе невалидного кода 2FA отображается сообщение об ошибке.
- [ ] Пустое поле кода 2FA не принимается.
- [ ] Повторная отправка кода работает корректно, если такая функция доступна.

## UI и поведение формы

- [ ] Фокус устанавливается в активное поле ввода.
- [ ] Клавиатура на mobile web не перекрывает основные элементы формы.
- [ ] Кнопка входа имеет понятное состояние.
- [ ] Ошибки не ломают отображение формы.
- [ ] После ошибки пользователь может исправить данные и повторить вход.

## Итоговая проверка

- [ ] Основные позитивные сценарии проверены.
- [ ] Основные негативные сценарии проверены.
- [ ] Проверена валидация обязательных полей.
- [ ] Проверены сообщения об ошибках.
- [ ] Проверено базовое отображение на mobile web.
