# Checklist: API Testing — Postman

## Environment

- [ ] Environment импортирован в Postman.
- [ ] Переменная `url` заполнена.
- [ ] Переменная `post_id` заполнена.
- [ ] Переменная `doesnt_exist_post_id` заполнена.
- [ ] Активирован нужный environment перед запуском коллекции.

## GET post by ID

- [ ] Запрос отправляется методом GET.
- [ ] Запрос отправляется на endpoint `/posts/{post_id}`.
- [ ] Статус-код ответа — 200.
- [ ] Ответ приходит в формате JSON.
- [ ] В ответе есть поле `id`.
- [ ] В ответе есть поле `title`.
- [ ] Значение `id` соответствует `post_id`.

## POST create post

- [ ] Запрос отправляется методом POST.
- [ ] Запрос отправляется на endpoint `/posts`.
- [ ] Body передаётся в формате JSON.
- [ ] Статус-код ответа — 201.
- [ ] В ответе есть поле `id`.
- [ ] Значение `title` соответствует отправленному значению.
- [ ] Значение `userId` соответствует отправленному значению.

## PUT update post

- [ ] Запрос отправляется методом PUT.
- [ ] Запрос отправляется на endpoint `/posts/{post_id}`.
- [ ] Body передаётся в формате JSON.
- [ ] Статус-код ответа — 200.
- [ ] Значение `id` соответствует `post_id`.
- [ ] Значение `title` обновлено.
- [ ] Значение `body` обновлено.

## DELETE post

- [ ] Запрос отправляется методом DELETE.
- [ ] Запрос отправляется на endpoint `/posts/{post_id}`.
- [ ] Статус-код ответа — 200.
- [ ] Ответ приходит без ошибки.
- [ ] Тело ответа соответствует ожидаемому формату.

## GET posts by title

- [ ] Запрос отправляется методом GET.
- [ ] В запросе используется query parameter `title`.
- [ ] Статус-код ответа — 200.
- [ ] Ответ приходит в формате массива.
- [ ] Все элементы массива содержат ожидаемое значение `title`.

## Negative scenario

- [ ] Запрос с несуществующим `post_id` отправляется методом GET.
- [ ] Статус-код ответа — 404.
- [ ] API корректно обрабатывает запрос к несуществующему ресурсу.

## Итоговая проверка

- [ ] Все запросы коллекции запускаются без ошибок.
- [ ] Все тесты Postman проходят успешно.
- [ ] Проверены позитивные сценарии.
- [ ] Проверен негативный сценарий.
- [ ] Подготовлен тестовый отчёт.
