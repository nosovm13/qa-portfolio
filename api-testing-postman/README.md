# API Testing —  Postman

Учебный проект по тестированию REST API с использованием Postman.

## Объект тестирования

JSONPlaceholder Posts API.

## Цель проекта

Показать базовые навыки API-тестирования: отправку HTTP-запросов, проверку статус-кодов, структуры JSON-ответа, позитивных и негативных сценариев.

## Что проверялось

- получение поста по ID;
- создание нового поста;
- обновление существующего поста;
- удаление поста;
- фильтрация постов по title;
- обработка запроса с несуществующим ID.

## HTTP-методы

- GET
- POST
- PUT
- DELETE

## Проверки в Postman

- проверка статус-кодов;
- проверка наличия полей в JSON-ответе;
- проверка значений полей `id`, `title`, `body`, `userId`;
- проверка массива в ответе;
- проверка обработки несуществующего ресурса.

## Инструменты

- Postman
- JSON
- REST API
- JavaScript

## Файлы

- `test_plan.md` — краткий тест-план;
- `checklist.md` — чек-лист API-проверок;
- `postman_collection.json` — коллекция Postman;
- `postman_environment.json` — окружение Postman;
- `test_report.md` — краткий отчёт по результатам тестирования.

## Примечание

Проект выполнен в учебных целях на публичном demo API. Реальные пользовательские данные не используются.
