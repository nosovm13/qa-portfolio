# Test Report: API Testing — Postman

## Объект тестирования

JSONPlaceholder Posts API.

## Цель тестирования

Проверить основные REST API-запросы для ресурса posts: получение, создание, обновление, удаление, фильтрацию и обработку несуществующего ID.

## Тестовая среда

- Инструмент: Postman
- API: JSONPlaceholder
- Формат данных: JSON

## Проверенные запросы

- GET post by ID;
- POST create post;
- PUT update post;
- DELETE post;
- GET posts by title;
- GET non-existing post.

## Виды тестирования

- API testing;
- functional testing;
- positive testing;
- negative testing;
- smoke testing.

## Проверки

В Postman были добавлены автопроверки для:

- статус-кодов `200`, `201`, `404`;
- наличия обязательных полей в JSON-ответе;
- соответствия `id` тестовым данным;
- соответствия `title`, `body`, `userId` ожидаемым значениям;
- проверки массива в ответе;
- проверки обработки несуществующего ресурса.

## Результат

Подготовлена Postman-коллекция с базовыми API-запросами и автопроверками. Проверены основные позитивные сценарии работы с ресурсом posts и один негативный сценарий с несуществующим ID.

## Ограничения

- Используется публичное demo API.
- Данные не сохраняются как в реальном production API.
- Не проверялись авторизация, безопасность, нагрузка и работа базы данных.

## Использованные инструменты

- Postman;
- JSON;
- JavaScript assertions.
