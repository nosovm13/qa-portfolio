# Checklist: PostgreSQL QA Practice

## Users

- [ ] Проверить пользователей с пустым email.
- [ ] Проверить пользователей с `NULL` в email.
- [ ] Проверить дубли email.
- [ ] Проверить пользователей с некорректным статусом.
- [ ] Проверить пользователей без заказов.
- [ ] Проверить пользователей, созданных в будущем.

## Products

- [ ] Проверить товары с пустым названием.
- [ ] Проверить товары с `NULL` в названии.
- [ ] Проверить товары с нулевой ценой.
- [ ] Проверить товары с отрицательной ценой.
- [ ] Проверить активные товары без заказов.
- [ ] Проверить товары, созданные в будущем.

## Orders

- [ ] Проверить заказы с некорректным статусом.
- [ ] Проверить заказы без существующего пользователя.
- [ ] Проверить заказы, созданные в будущем.
- [ ] Проверить количество заказов по статусам.
- [ ] Проверить соответствие суммы заказа сумме позиций заказа.

## Order Items

- [ ] Проверить позиции заказа с нулевым количеством.
- [ ] Проверить позиции заказа с отрицательным количеством.
- [ ] Проверить позиции заказа с нулевой ценой.
- [ ] Проверить позиции заказа с отрицательной ценой.
- [ ] Проверить позиции заказа без существующего товара.
- [ ] Проверить расчёт суммы позиции заказа.

## Итоговая проверка

- [ ] Все SQL-запросы выполняются без синтаксических ошибок.
- [ ] Запросы возвращают ожидаемые проблемные записи на тестовых данных.
- [ ] Проверены связи между таблицами.
- [ ] Проверены основные проверки качества данных.
- [ ] Подготовлен краткий отчёт по проекту.
