# PostgreSQL QA Practice

Учебный проект с SQL-запросами для проверки данных.

Проект демонстрирует базовые навыки SQL, которые могут использоваться QA Engineer при тестировании web-сервисов, API и бизнес-приложений.

## Что проверяется

- поиск дублей;
- поиск пустых обязательных полей;
- проверка некорректных статусов;
- проверка связей между таблицами;
- поиск заказов без пользователя;
- проверка отрицательных или нулевых значений;
- проверка соответствия суммы заказа данным в позициях заказа.

## Используемые SQL-конструкции

- SELECT
- WHERE
- JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- COUNT
- SUM
- CASE

## Файлы

- `schema.sql` — пример структуры тестовой базы данных;
- `sql_queries.sql` — SQL-запросы для QA-проверок.

## Примечание

Проект выполнен в учебных целях. Все данные демонстрационные.
