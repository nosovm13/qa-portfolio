# PostgreSQL QA Practice

Учебный проект с SQL-запросами для проверки данных в PostgreSQL.

Проект демонстрирует базовые навыки SQL, которые QA Engineer может использовать при тестировании web-сервисов, API, личных кабинетов, заказов, пользователей и бизнес-приложений.

## Объект тестирования

Демонстрационная база данных интернет-сервиса с пользователями, товарами, заказами и позициями заказов.

## Что проверяется

- поиск пустых обязательных полей;
- поиск дублей;
- проверка некорректных статусов;
- проверка отрицательных и нулевых значений;
- проверка связей между таблицами;
- поиск пользователей без заказов;
- поиск товаров без заказов;
- проверка соответствия суммы заказа позициям заказа;
- поиск заказов, созданных в будущем.

## Используемая СУБД

PostgreSQL

## Используемые SQL-конструкции

- SELECT
- WHERE
- JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- COUNT
- SUM
- COALESCE
- IS NULL
- IS DISTINCT FROM
- CASE

## Файлы

- `schema.sql` — структура демонстрационной базы данных;
- `test_data.sql` — тестовые данные;
- `sql_queries.sql` — SQL-запросы для QA-проверок;
- `checklist.md` — чек-лист SQL-проверок;
- `test_report.md` — краткий отчёт по проекту.
