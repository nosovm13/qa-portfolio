# Test Report: PostgreSQL QA Practice

## Объект тестирования

Демонстрационная база данных PostgreSQL с таблицами:

- `users`;
- `products`;
- `orders`;
- `order_items`.

## Цель проекта

Подготовить набор SQL-запросов для проверки качества данных и базовой бизнес-логики в демонстрационной базе данных.

## Тестовая среда

- СУБД: PostgreSQL
- Язык запросов: SQL
- Формат проекта: учебная демонстрационная база данных

## Проверенные области

- пользователи;
- товары;
- заказы;
- позиции заказов;
- связи между таблицами;
- корректность статусов;
- корректность обязательных полей;
- корректность числовых значений;
- соответствие суммы заказа позициям заказа.

## Подготовленные проверки

В проекте подготовлены SQL-запросы для:

- поиска пустых email;
- поиска дублей email;
- поиска некорректных статусов пользователей;
- поиска товаров с пустым названием;
- поиска товаров с нулевой или отрицательной ценой;
- поиска заказов с некорректным статусом;
- поиска пользователей без заказов;
- поиска позиций заказа с некорректным количеством;
- поиска активных товаров без заказов;
- проверки суммы заказа по позициям заказа;
- поиска записей, созданных в будущем.

## Использованные SQL-конструкции

- SELECT
- WHERE
- JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- COUNT
- SUM
- COALESCE
- IS NULL
- IS DISTINCT FROM
- CASE

## Результат

Подготовлен учебный SQL-проект для демонстрации базовых навыков QA Engineer при работе с PostgreSQL.

Проект показывает умение проверять данные, находить аномалии, работать со связями между таблицами и составлять SQL-запросы для типовых QA-задач.

## Ограничения

- Проект выполнен в учебных целях.
- Используются демонстрационные данные.
- Не проверяется производительность SQL-запросов.
- Не проверяются права доступа, транзакции, индексы и хранимые процедуры.
